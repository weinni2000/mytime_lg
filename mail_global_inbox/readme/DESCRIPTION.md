Provides a global inbox that shows every incoming email received by Odoo in a single
list, regardless of which model or document the email was attached to.

The view is accessible via **Discuss → All Emails** and lists emails sorted by date
(newest first) with columns for subject, sender, the target model, and the linked
record. A button on each row opens the related document directly.

Each email can be marked as reviewed by assigning the *Checked By* field to a user,
making it easy for a team to track which vendor or customer communications have
already been processed.
